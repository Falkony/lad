# Потребности, накопления и резервы

Итерация 6: миграция 13, копии версии 8; версии 1–7 читаются с преобразованием.

Карточка цели хранит обязательность, стоимость, приоритет, срок, месяц покупки, ID категории
и план месячных пополнений. Переходы между идеей, накоплением и планом свободны. Завершение
новой карточки требует связанной покупки; отмена освобождает резервы и сохраняет историю.
Возврат создаёт/связывает доход и относится к прежней покупке, допускаются частичные возвраты
в пределах её стоимости. Полный возврат возвращает карточку в накопления. Удаление операции
не стирает связь: покупка снова ожидает решения; восстановление возвращает её состояние.

`goals.funding` — предметная история: записи резервирования/изъятия по ID счетов и покупки
со связанными возвратами. Изменяется только серверными командами под workspace_guard,
вместе с журналом. Резерв не является переводом и не меняет остаток. Деньги одного счёта
нельзя назначить нескольким целям сверх фактического остатка. Кредитные деньги исключены.
Расход/перевод, нарушающий уже созданные резервы, отклоняется: сначала освободите назначение.
История ограничена 2000 записями на цель; карточка с историей отменяется вместо удаления.

Старое поле `saved` преобразуется в оценку без счёта (`unassigned`). Она не выдаётся за
подтверждённый резерв и не уменьшает свободные деньги. Резервирование привязывает эту оценку
к реальным счетам, уменьшая её остаток. `saved` затем пересчитывается из истории и оценки.
Фактический перевод между счетами записывается отдельно в разделе операций.

Статус «Запланировано» с категорией и месяцем создаёт план `source: goal`. Он включён
в бюджет и прогноз; подтверждение в календаре связывает расход с целью и освобождает резерв.
Изменение месяца/срока обновляет будущую версию плана. Прямая покупка из карточки также
атомарно создаёт расход, снимает назначение и завершает цель. Отмена карточки не удаляет расход
и не создаёт возврат: возврат денег — отдельное явное действие.

Доступное для решений — минимум прогноза собственных денег на 90 дней после резервов.
Если прогноз уже включает покупку цели, её резерв освобождается на дату покупки, чтобы
не вычитать его дважды. Обязательства входят через общий прогноз. Оценка достижения срока
использует привязанные резервы и месячный план пополнений; обещанные пополнения не становятся
фактическими деньгами. Полный экспорт сохраняет назначения, историю, связи и планы.
