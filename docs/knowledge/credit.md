# Кредитные карты и график банка

Итерация 5b: миграция 12, резервные копии версии 7 (чтение версий 1–6 сохранено).

Кредитная карта — счёт `kind: credit`. Отрицательный остаток означает долг; доступно =
лимит + остаток. Лимит положителен, превышение и архивация с долгом отклоняются атомарно
через `syncCreditCards` в `finishCommand`, включая импорт, сверки и удаление операций.
Карта по умолчанию исключена из прогноза собственных денег.

Параметры карты: лимит, минимальный платёж из выписки, день платежа, льготная дата,
счёт погашения и выбор полного/минимального платежа. Льготную дату вводит пользователь:
приложение не вычисляет банковский расчётный период. График `source: credit` использует
общую модель планов. Подтверждение создаёт перевод с собственного счёта на карту;
повторное подтверждение идемпотентно. Покупка остаётся расходом, погашение не дублирует его
в бюджете. План отражает введённую выписку; следующая дата определяется после подтверждения,
а новые выписки и условия льготного периода требуют обновления пользователем.

Прогноз проводит обе стороны перевода; внутри включённых счетов он не меняет общую сумму.
Для карты дефицит — остаток ниже отрицательного лимита. Раздел счетов показывает доступный
лимит сейчас и его минимум на 90 дней. Незаписанные будущие покупки не прогнозируются.

Обязательство может содержать `bankSchedule`: уникальные даты, суммы и необязательные проценты.
В форме строка имеет вид `2026-12-10; 15000; 2000` (рубли). Такой график заменяет будущие
расчётные даты и суммы, сохраняя решения по уже подтверждённым датам. Поля `customDates`
хранятся также в версиях планов. Проценты банка имеют приоритет; иначе применяется
выбранная оценка: ставка/12 или actual/365 по прошедшим календарным дням.
Расчёт — bigint с округлением до копейки. Високосный год меняет число дней, знаменатель — 365.
При ручном погашении пользователь может поправить разбиение на долг, проценты и комиссии.
Отмена и удаление связанной операции возвращают долг через прежнюю историю погашений.

превышении лимита, прогноз обеих сторон, удаление/восстановление, даты банка и високосный день.
